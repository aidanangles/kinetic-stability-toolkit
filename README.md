# Kinetic Stability Modeling Toolkit

**Status:** Planning. No results yet.

## Question

How much shorter can stability studies be while still supporting shelf life, excursion decisions, and release limits?

## Approach

Fit Šesták–Berggren-type models across temperatures, select forms using AIC/BIC, and report prediction intervals; compare with the classical linear 95% confidence-interval method.

## First step

Reproduce published vaccine or mAb results (including holding out 5°C data), then add an excursion calculator and an internal release-limit calculator.
